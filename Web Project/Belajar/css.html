CSS-Font

Di CSS terdapat di declaration yaitu property dan value
Property adalah nama dari atribut yang akan diubah, sedangkan value adalah nilai dari atribut
Berikut adalah contoh dari CSS-Font:

  • Font-Family
      Mengatur Jenis Font
    1. nama font
    2. generic family

  • Font-Size
      Mengatur Ukuran Font
    1. px
    2. em
    3. %

  • Font-Weight
      Mengukur Ketebalan Font
    1. lighter
    2. normal
    3. 100-900
    4. bold
    5. bolder

  • Font-Variant
      Mengubah Font menjadi small caps
    1. normal
    2. small-caps

  • Font-Style
      Mengubah Font Menjadi Bercetak Miring
    1. normal
    2. italic
    3. oblique
  • Line-Height
      Mengatur Spasi Antar Baris
    1. normal
    2. px
    3. em


bisa di singkat menjadi:
      berawal dari 6 baris:

      body {
        font-style: italic;
        font-variant: normal;
        font-weight: bold;
        font-size: 16px;
        line-height: 18px;
        font-family: helvetica, arial, sans-serif;
      }

      menjadi 1 baris:
      body {
        font: italic normal bold 16px/18px helvetica, arial, sans-serif;
      }
      urutan harus sesuai mulai dari:
      1. font-style
      2. font-variant
      3. font-weight
      4. font-size 
      5. line-height
      6. font-family

CSS-Selector

digunakan pada css untuk mengenali elemen HTML untuk di style

    Selector
  • elemen HTML
  • id
    1. Sebuah elemen HTML hanya boleh memiliki 1 ID
    2. Setiap halaman hanya boleh memiliki 1 elemen dengan id tersebut
    3. Dapat digunakan sebagai penanda halaman untuk link
    4. Digunakan juga untuk javascript
    5. Sebaiknya tidak digunakan untuk CSS (lebih baik gunakan class)
  • class
  • complex selector
      ini macam-macam seperator
      h1,h2{
        color: blue;
      }
      ul li a {
        color: red;
      }

      untuk class itu cara panggilnya menggunakan (.) misal class="p1"
      .p1{
        color: blue;
      }
      untuk id itu cara panggilnya menggunakan (#) misal id="p2"
      #p2{
        color: red;
      }

CSS-Pseudo-class

kelas semu yang dimiliki ole sebuah elemen HTML, yang membuat kita dapat mendefinisikan style pada "keadaan tertentu" dari elemen tersebut.
Pseudo-class yang berhubungan dengan link

  • :link
      style default pada sebuah link (a yang memiliki href)
  • :hover
      style ketika kursor mouse berada diatas sebuah link / elemen
  • :active
      style ketika sebuah link di-klik(keadaan aktif)
  • :visited
      style ketika sebuah link sudah pernah dikunjungi sebelumnya (menggunakan browser yang sama)
  • first-child
      memilih elemen pertama dari sebuah parent (elemen pembungkusnya)
  • :last-child
      memilih elemen terakhir dari sebuah parent (elemen pembungkusnya)
  • :nth-child(n)
      memilih elemen ke-n dari sebuah parent (elemen pembungkusnya)
      n bisa berarti urutan (1),(2), ... atau pola (2n), (3n+2), (4n-1) atau ganjil dan genap (even) & (odd)
li:first-child p{
      color: blue;
    }
    jadi elemen pertama dari list item akan berwarna biru
     dalam artian tolong carikan saya dari elemen li anak pertama dari a
    tolong ubah warnanya menjadi biru

    dan untuk nth-child kalian isi dari urutan a yang banyak pada li, 
    ingin anak keberapa yang kalian rubah
    jika ingin kelipatan 3 maka (3n) dan jika ingin mulai kelipatan 3
     dari satu tulis saja dengan (3n+1) atau (3n-2)
     (even) untuk genap, (odd) untuk ganjil
  • :first-of-type
      memilih elemen pertama dari sebuah jenis elemen tertentu / tipe tag
  • last-of-type
      memilih elemen terakhir dari sebuah jenis / tipe tag

CSS-Inheritance

sebuah elemen mewarisi beberapa nilai dari properti yang dimiliki oleh element parent-nya

  • color
  • font
  • letter-spacing
  • line-height
  • list-style
  • text-align
  • text-indent
  • text-transform
  • visibility
  • white-space
jadi bila tag body melakukan intruksi color green
    agar semua elemen di dalamnya warna grey terkecuali a, karena tag a itu menolak Color
    maka caranya intruksikan di bawah body dengana{
      color: inherit;
    }
    artinya a mengikut ke body

CSS-display

tag pada HTML digunakan untuk memberikan 'maksud' / 'arti pada sebuah konten (p untuk paragraf, h1 unutk heading utama, dll)
tag div> dan span> tidak memiliki 'arti' apapun, keduanya digunakan untuk mengelompokkan tag-tag HTML dan memberikan infoemasi terhadap tag-tag tersebut.
setiap tag pada HTML berada di dalam sebuah kotak. prperti display pada CSS mengatur perilaku dari kotak tersebut.
setiap tag pada HTML memiliki nilai default untuk properti display. Tetapi kita juga dapat mengubah prilaku dari tag tersebut dengan mengganti value-nya

  • div
    1. display defaultnya display: block;
  • span
    1. display defaultnya display: inline;
  • display
    1. inline
      • Elemen HTML yang secara default tidak menambahkan baris baru ketika dibuat
      • Lebar dan tinggi elemennya sebesar konten yang ada di dalamnya
      • Kita tidak dapat mengatur tinggi dan lebar dari elemen inline(hanya elemen image saja yang bisa di rubah)
      • Margin dan padding hanya mempengaruhi elemen secara horizontal, tidak vertikal
      • elemen inline: b, strong, i, em, a, span, sub, sup, button, input, label, select, textarea, ...
    2. inline-block
      • Tidak ada elemen yang secara default memiliki properti display: inline-block;
      • Kita harus ubah secara manual properti tersebut
      • Perilaku dasarnya sama dengan elemen inline
      • Perbedaannya, elemen inline-block dapat kita atur tinggi dan lebar-nya
    3. block
      • Elemen HTML yang secara default menambahkan baris baru ketika dibuat
      • Jika tidak diatur lebar-nya, maka lebar default dari elemen block akan memenuhi lebar dari browser / parent-nya
      • Kita dapat mengatur tinggi dan lebar dari elemen block
      • Di dalam elemen block, kita dapat menyimpan tag dengan elemen inline, inline-block, atau bahkan elemen block lagi
      • elemen block: h1-h6, p, ol, ul, li, form, hr, div, ...
    4. none
