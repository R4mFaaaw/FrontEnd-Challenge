Apa itu Python?

Python merupakan bahasa programming yang popular. dibuat oleh Guido van Rossum, dan terbit di tahun 1991

Di gunakan untuk:

  • Web development (server-side)
  • Software development
  • mathematics
  • system scripting

Apa yang bisa python lakukan?


  • Python bisa untuk di gunakan di server dalam pembuatan website
  • Python bisa di gunakan untuk Software untuk membuat workflow
  • Python bisa untuk menghubungkan database system, bisa membaca dan merubah file
  • Python bisa untuk mengatasi big data dan matematika yang complex
  • Python bisa digunakan untuk prototyping, or for production-ready software development


Kenapa Python?


  • Python bekerja di berbagai platform (windows, Mac, Linuc, Raspberry Pi, etc.)
  • Python syntax nya serupa dengan bahasa inggris
  • Python mempunyai syntax yang mengizinkan developersnya untuk menulis program yang pendek tidak seperti bahasa pemrograman yang lain
  • Python sangat cepat untuk di jalankan karena berjalan di interpreter system
  • Python can be treated in a procedural way, an object-oriented way or a functional way.
