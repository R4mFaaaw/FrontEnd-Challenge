Apa itu Git dan Github

Git dan Github merupakan definisi berbeda bukan sama
Git sendiri merupakan VCS atau Version System Control
Version Control System, disebut juga revision control system adalah sistem yang mengelola perubahan dari sebuah dokumen, program komputer, website dan kumpulan informasi lain
kenapa kita perlu membuat Git karena untuk kolaborasi

Version Control System

  • Sebuah sistem yang menyimpan 'rekaman / snapshot' perubahan pada source code
  • Memungkinkan bekerja berkolaborasi dengan lebih baik
  • Mengetahui siapa yang melakukan dan kapan sebuah perubahan terjadi
  • Memungkinkan kita untuk kembali ke keadaan sebelum perubahan (checkout)

    • selain git ada juga subversion (svn), mercurial, cvs

Jadi Git itu apa sih?

Git

Sebuah VCS terdistribusi untuk mengelola perubahan file di dalam folder.
file di dalam folder git itu bisa di sebut dengan (repository/ repo)
Riwayat perubahan file disimpan menggunakan serangkaian commit.

Kalo misal tanpa Git?

file yang tersimpan akan 1, jadi bahasa kotornya tidak ada timeline, apabila menggunakan git dan membuat suatu file maka dia akan ada timeline perubahan pada suatu file yaitu dengan commit, misal pada studi kasus skripsi, di hari pertama kamu sedang mengerjakan bab1 dan hari seterusnya mengerjakan bab 2,3,4,5 sementara itu apabila tidak menggunakan git, itu file akan secara otomatis tersimpan, apabila menggunakan git, kamu setiap hari merubah file tersebut tercatat/terekam dengan commit
commit yang sudah menjadi timeline dari atas kebawah atau bisa juga jadi vertical, bila ada yang mau mengerjakan di file commit yang sama dan keluar dari urutan git repo itu disebut dengan Branch

Istilah Git

  • repo: Folder project kita
  • commit: rekaman / snapshot dari repo kita
  • hash: penanda unik pada sebuah commit
  • checkout: berpindah ke sebuah commit
  • branch: cabang bebas dari sebuah commit
  • merge: menggabungkan branch
  • remote: sumber yang memiliki repo
  • clone: mengambil repo dari remote
  • push: mengirimkan commit ke repo
  • pull: mengambil commit dari repo

Apa itu Github?

Layanan cloud untuk menyimpan & mengelola project / repo git. instagram-nya para programmer bisa like, modifikasi dan lain-lain
